# M4 — Modern experience report

Status: **complete for the implemented scope** (2026-11-17); four cosmetic
extras are explicitly deferred.

## Delivered

### Settings (two-process verified)
- `BrowserSettings` extended with a theme mode; persisted atomically as
  `settings.json` through a single ordered background writer.
- Settings page (Cmd+, / gear button): homepage, search-engine template,
  System/Light/Dark theme buttons, clear-site-data and clear-history actions.
  Invalid search templates without `{query}` are rejected with an inline error.
- `m4-probe` proves, across two separate processes and a server on a fixed port:
  - edits update memory and `settings.json`;
  - an address-bar search uses the edited engine (`/search?q=hello+world`);
  - a fresh relaunch opens the saved homepage;
  - the saved search engine and dark theme are restored and used.

### Themes
- Light and dark palettes with a system option; the theme follows the OS when
  set to System and updates live on appearance changes. Applied to all chrome
  surfaces, overlays and components through the GPUI theme global.

### Command palette (Cmd+K)
- Commands (new tab, history, bookmarks, downloads, settings, find, reload,
  clear site data), bookmarks, recent history, and a context-sensitive
  "Go to …" / "Search for …" entry for typed text.
- Up/Down (and Ctrl-P/Ctrl-N) move the selection, Enter runs it, Esc closes,
  clicking a row runs it. Verified through the real input entity + selection
  API (`m4-probe`): command execution opened a tab, typed URL navigation worked,
  and selection moved with the keyboard actions.

### New-tab page
- GPUI page with quick actions (history, bookmarks, downloads, settings) and up
  to eight recent sites loaded from history SQLite; clicking opens the site.
- Keeps the native page view hidden (ADR-0003).

### Bookmark bar
- A compact bar under the toolbar listing unfiled bookmarks; click to navigate,
  trailing button opens the manager. Shown only when bookmarks exist.

### Already in place from earlier milestones
- Light/dark chrome, native titlebar/traffic-light integration, compact
  toolbar, favicons, per-tab loading indicators, downloads/find overlays.

## Verification

`m4-probe` phase 1:
```
edited            homepage updated in memory
settings_file     settings.json contains homepage/search/theme
search            /search?q=hello+world via configured engine
settings_page     overlay opens
new_tab           2 recent sites, 1 bookmark in bar
palette_command   New Tab command opened a tab
palette_url       typed URL navigated
palette_keys      up/down selection works
```
phase 2 (new process, same data dir + server port):
```
homepage_restored      startup loaded the saved homepage
settings_restored      dark theme + saved search template loaded
search_after_restart   /search?q=again
```

All earlier probes (M0–M3) and the quality gates still pass.

## Deferred (documented)

- Customizable toolbar ordering and a sidebar: the toolbar is fixed and
  compact; a sidebar needs new layout/navigation design and is scheduled with
  tab groups.
- Pinned tabs and tab grouping: need persistence schema extensions and tab-strip
  drag semantics; deferred to a post-1.0 slice.
- Bookmark import/export: requires native file panels and an HTML/JSON import
  format; deferred to M6.
- Downloads are session-only (no persisted download list).

These deferrals do not block the daily-use acceptance criteria; they are UX
depth, not missing core capabilities.

# M6 — Release hardening report

Status: **complete** (2026-11-17)

## Delivered

### Performance baseline (measured, not guessed)
`scripts/perf.sh` + `perf-probe` (release build, deterministic local fixtures):

| Run | Tabs | Startup | Nav | Host | WebKit | Total | Idle CPU |
| --- | --- | --- | --- | --- | --- | --- | --- |
| cold | 1 | 375 ms | 46 ms | 111 MB | 64 MB | 175 MB | 1.0% |
| warm | 1 | 404 ms | 41 ms | 111 MB | 64 MB | 175 MB | 0.7% |
| warm | 5 | 402 ms | 38 ms | 107 MB | 180 MB | 287 MB | 1.3% |
| warm | 10 | 414 ms | 32 ms | 108 MB | 314 MB | 422 MB | 1.7% |

- Binary 11.7 MB; `.app` 12.7 MB.
- ~29 MB per extra tab (one WebContent process per view). Documented as engine
  cost; hibernation is backlog.
- Methodology and limits: `docs/testing/performance.md`.

### Optimizations
- Adaptive engine ticker: 80 ms while busy, 1.2 s idle; metadata IPC every fourth
  idle tick. Idle CPU stays around 1–1.7% on this host.
- Ordered background writers for session/settings, background icon fetches,
  lazy session restore, one engine per tab, release LTO + strip.

### Packaging
- `scripts/package.sh` builds `target/package/GPUI Browser.app` with:
  - `Info.plist` (identifier `com.gpuibrowser.app`, name, version, minimum
    macOS 13, high-resolution, camera/microphone usage descriptions),
  - generated `AppIcon.icns`,
  - ad-hoc code signature.
- Verified the bundle launches as a native app (process + window, no crash).
- Not notarized; no hardened runtime/sandbox yet — documented, not claimed.

### Native menus
- App menu (Services/Quit), File (New Tab, New Private Window, Close Tab),
  View (Reload, hard reload, zoom, find), History (history/downloads),
  Bookmarks (bookmark page, manager). Shortcut labels come from the keymap.

### Lifecycle
- `scripts/lifecycle-probe.sh` proves Cmd+Q quits and closing the last tab
  closes the window and quits the app (measured 1.01 s and 0.50 s), with no
  zombie process.
- Last window closed → app exits, like a standard document app
  (`cx.on_window_closed` + empty-window check).

### Bundle smoke
- `scripts/bundle-smoke.sh` validates Info.plist, the ad-hoc signature, a real
  launch of the bundled binary with isolated data directories, a WebKit content
  process being spawned, and clean termination: **PASS**.
- Final bundle: 12,708 KB, binary 11,941,856 bytes.
- Idle CPU at 10 tabs after adaptive polling: 1.67%.

### CI
- `.github/workflows/ci.yml`: fmt, check, clippy `-D warnings`, tests on
  `macos-14`. GUI probes require a WindowServer session and are documented as
  local/self-hosted.

### Documentation
- README build/run/package/probe instructions and shortcuts.
- `docs/testing/performance.md`, this report, ADRs 0001–0008.
- `SECURITY.md` with explicit non-guarantees.

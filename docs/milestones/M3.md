# M3 — Browser essentials report

Status: **complete for the implemented scope** (2026-11-17). Two items are
explicitly deferred (see below), not silently omitted.

## Delivered

### History
- SQLite store (`history` table) with one row per URL, visit counts, last-visit
  ordering and escaped LIKE search.
- Recording on every completed http(s) main-frame load.
- GPUI history page (Cmd+Y / toolbar clock) listing recent visits with relative
  times; click to navigate, per-row delete, clear all.
- The page hides the native web view; closing restores it (ADR-0003 policy).

### Bookmarks and folders
- SQLite `bookmarks` + `bookmark_folders` tables with URL uniqueness, folder
  reassignment and `ON DELETE SET NULL` when a folder is deleted.
- Star toggle in the toolbar / Cmd+D for the active page.
- Bookmarks page (Cmd+Shift+B / toolbar list): unfiled section plus each folder,
  open/delete rows, save the current page into a folder, delete folders.
- "New Folder" GPUI modal using the real text input (Enter creates, Esc
  cancels).
- Persistence verified by reloading from SQLite after each mutation.

### Downloads
- WebKit `WKDownload` integration: response policy turns non-displayable
  responses and `Content-Disposition: attachment` into downloads; a
  `WKDownloadDelegate` chooses a destination.
- Filename sanitisation and collision handling in `browser-security` (pure
  tests), always inside the downloads directory.
- Downloads page (Cmd+Shift+J / toolbar arrow): filename, path, sampled
  progress bytes, status, Open, Reveal in Finder, Cancel.
- Verified end-to-end with the fixture `/download` (`payload.txt` contents
  checked on disk).

### Find in page
- `WKWebView findString:withConfiguration:` (wrap, case-insensitive, forward /
  backward).
- GPUI find bar integrated into the chrome (so it can appear above page content
  by shrinking the page viewport): live search, next/previous, match/no-match
  status, Esc closes and returns focus to the page.

### Clear browsing data
- `WKWebsiteDataStore.removeDataOfTypes:modifiedSince:` over all WebKit data
  types (cookies, caches, local storage, IndexedDB, service workers, ...).
- Button on the history page; status feedback.
- Verified with a fixture that writes a cookie and localStorage, then reloads
  after clearing: title goes from `storage-set-set` to `storage-clear-clear`.

### Other essentials
- Copy URL (Cmd+Shift+C) to the clipboard.
- Zoom in/out/reset (Cmd+= / Cmd+- / Cmd+0) via `WKWebView.pageZoom`.
- Zoom and window-fit behavior already verified by the M0/M1 probes.
- Search engine + homepage settings model (`BrowserSettings`) with tested
  defaults and sanitisation.

Unit tests: 41 in `browser-core`, 15 in `browser-storage`, 5 in
`browser-security`, 2 test-server, plus favicon tests. Quality gates
(`fmt`, `check`, `clippy -D warnings`, `test`) pass; M0/M1/M2 probes still pass.

## Deferred (documented, not hidden)

- **Permission prompts (camera/microphone)**: the `WKUIDelegate` currently
  denies media capture by default. Building a prompt requires parking a
  WebKit decision block across a GPUI dialog; this lands with the M5 privacy
  work, together with a persistent per-origin permission model.
- **Chrome context menus**: page context menus are WebKit's native menus today.
  Right-click menus for tabs/bookmarks and "open link in new tab" from the page
  menu need native NSMenu/`WKUIDelegate` work and are scheduled for M4.
- Per-site cookie inspection/management UI and notification/location
  permissions: M5.

## Known limitations

- Downloads have no WebKit progress callback; progress is sampled from the
  destination file size, and resume is unsupported.
- Find highlights are owned by WebKit and may remain painted until the next
  find or navigation after closing the bar.
- History search exists in storage but the UI currently lists recent entries
  only.

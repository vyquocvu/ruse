# M1 — Browser foundation report

Status: **complete and verified** (2026-11-17)

## Delivered

- **Domain models (`browser-core`)** — pure and unit-tested (31 tests):
  - address-bar resolution: explicit schemes, bare hosts to HTTPS, localhost and
    ports, search queries, rejection of `javascript:` navigation,
  - navigation state machine (started/committed/finished/failed/stopped,
    process termination, progress monotonicity, title fallback),
  - tab collection (open/close/activate/cycle/reorder/duplicate/recently closed
    with bounded history),
  - search engine templates with query encoding,
  - `BrowserSettings` defaults and sanitation.
- **Chrome (`browser-ui`)** — dark/light theme tokens, icon/text buttons, tab
  chips, loading bar, native web-content host, and a real single-line text
  input implementing GPUI's `EntityInputHandler` (selection, clipboard, IME
  marked text, horizontal caret scrolling).
- **App (`browser-app`)** — tab strip, navigation toolbar, address bar,
  loading progress, error page, GPUI new-tab page, per-tab engine event pumps,
  engine progress/title/URL polling, window title updates, focus handoff between
  chrome and page, keyboard action handlers.
- **Platform (`browser-platform`)** — AppKit parent-view extraction, a local
  `NSEvent` monitor forwarded to the browser (Cmd+L/[/]/R/T/W/Shift+T, Ctrl-Tab,
  zoom, quit), chrome focus restoration, external URL handoff, and synthetic
  key events for automated probes.
- **Harness** — `scripts/m1-probe.sh` drives the real browser window.

## Manual verification still required

These cannot be automated in this environment (no screen-recording permission,
no physical keyboard):

- Chrome pixels and typography at retina scale.
- Trackpad scrolling, text selection by dragging, context menus.
- Real key interception by the local `NSEvent` monitor (synthetic events bypass
  local monitors; GPUI action dispatch is covered).
- IME candidate window placement for non-Latin input.
- Link clicks and form submissions inside the page (native WebKit input; a
  fixture exists for future probes).

Checklist: `docs/testing/manual-checklist.md`.

## Known gaps carried into later milestones

- History/bookmarks storage (M3), downloads (M3), settings UI (M4), session
  persistence (M2), favicons (M2), find-in-page (M3), private windows (M5).
- New-tab page is intentionally minimal until M2.
- GPUI cannot draw above the native page view; the error/new-tab pages hide the
  page view and draw full-window GPUI surfaces (ADR-0003).
